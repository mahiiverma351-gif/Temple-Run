A fun, browser-based endless runner game inspired by Temple Run, built using HTML, CSS, and JavaScript.

🎮 About the Game

Jungle Escape is an endless running game where players navigate a jungle track, avoid obstacles, jump over rocks, slide under barriers, and collect coins to increase their score.

The goal is simple: survive for as long as possible and achieve the highest score!

✨ Features

🏃 Three-lane running gameplay

⬅️➡️ Left and right movement

⬆️ Jump over rocks

⬇️ Slide under barriers

🪙 Collect coins and earn points

📊 Live score and coin counter

🌴 Jungle-themed graphics

🔄 Restart the game anytime

💻 Runs directly in a web browser

📱 Responsive page layout

🛠️ Technologies Used

HTML5 – Game structure

CSS3 – Styling and layout

JavaScript – Game logic, movement, collisions, and scoring

Canvas API – Drawing the game environment and characters

📂 Project Structure

JungleEscape/
├── index.html
└── README.md

The CSS and JavaScript are included inside index.html, so separate files are not required.

🚀 How to Run

Download or clone this repository.

Open the project folder.

Open index.html in Google Chrome or another modern browser.

Click Start / Restart to begin playing.

Use the keyboard or on-screen buttons to control the player.

No additional libraries or installations are required.
